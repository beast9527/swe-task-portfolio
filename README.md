# SWE Task Portfolio

A small collection of software-engineering task examples based on public open-source repositories. The tasks cover database evolution, developer tooling, and configuration systems.

## Tasks

| Task | Language | Repository | Focus |
| --- | --- | --- | --- |
| [Versioned SQLite Schema Upgrade](tasks/01-versioned-sqlite-schema-upgrade) | Python | [`Senth/minecraft-mod-manager`](https://github.com/Senth/minecraft-mod-manager) | Schema migration, backup, rollback and integrity verification |
| [Token-Level Source Range Tracking](tasks/02-token-level-source-range-tracking) | JavaScript | [`csstree/csstree`](https://github.com/csstree/csstree) | Token locations and location-aware lexer diagnostics |
| [Layered Configuration Precedence](tasks/03-layered-config-precedence) | Python | [`Senth/minecraft-mod-manager`](https://github.com/Senth/minecraft-mod-manager) | Config discovery, precedence, validation and CLI integration |

Each task includes its specification, repository revision, container environment, test patch and reference solution patch.
